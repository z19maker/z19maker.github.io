## JAX vs. NumPy

- JAX provides a NumPy inspired interface for convenience
- duck-typing = an application of the duck test - if it walks like a duck and it quacks like a duck, then it must be a duck.
- thru duck-typing, Jax arrays can often be used as drop in replacements of NumPy arrays.
- Jax arrays are always immutable.

`jax.jit` = default JAX executes operations one at a time 
- just in time (JIT) compilation decorator, sequences of operations can be optimized together and run at once

**not all JAX code can be JIT compiled, as it requires array shapes to be static known at compile time.**

Demonstration on creating a just in time compiled function

This function performs standardization. Z Score normalization. 

Input is a dataset. 

This function transforms the data so that each column has a mean of 0 and a standard deviation of 1. 

`X - X.mean(0)` centers the data. 
By calculating the mean.
And subtracting it from every element. 
The result is that the columns average is zero. 

`X / X.std(0)` scales the data. 
Dividing each element by the standard deviation of its column, the function ensures that the spread of the data is consistent across all features, resulting in a unit standard deviation of 1. 

For machine learning this is important to do on each column so that features (columns) with large numerical ranges won't dominate the learning process. Ensuring that the model treats all input variables on an equal scale. 

```
import jax.numpy as jnp

def norm(X):
  X = X - X.mean(0)
  return X / X.std(0)
```

```
from jax import jit
norm_compiled = jit(norm)
```

```
np.random.seed(1701)
X = jnp.array(np.random.rand(10000, 10))
np.allclose(norm(X), norm_compiled(X), atol=1E-6)
```

```
%timeit norm(X).block_until_ready()
%timeit norm_compiled(X).block_until_ready()
```

Pretty cool. 

Limitations
requires all arrays to have static shapes
means that some JAX operations are incompatible with JIT compilations. 

This operation can be executed in op by op mode
But returns an error if you attempt to execute in JIT mode
This is because the function generates an array who's shape is not known at compile time: the size of the output depends on the values of the input array, and so it is not compatible with JIT.
